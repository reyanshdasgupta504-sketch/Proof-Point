# PROOFPOINT — Research & Evidence Workspace

Organise claims. Track sources. Examine evidence.

PROOFPOINT is a research workspace designed to help users organise claims, document sources, and review evidence in one place.

Live Demo

"Launch PROOFPOINT" (https://proofpoint-research-evidence-workspace-yuy1el.v2.appdeploy.ai/)

Features

- Claim organisation
- Evidence recording
- Source tracking
- Supporting and challenging evidence
- Research workspace
- Structured information management

Technology

- HTML
- CSS
- JavaScript

Project Status

This repository contains an independent reconstruction of the PROOFPOINT project. It is not the original deployment source code.

PROOFPOINT is a research organiser, not an automated fact-checking authority.
